Airtable Setup Guide

  1. Create a free account at airtable.com and create a new Base called Lemontag
  2. In your base, create 3 tables: Listings, Keepers, and Offers with the fields from the setup guide provided by Lemontag.
  3. Go to airtable.com/create/tokens → Create a Personal Access Token with data.records:read and data.records:write scopes on your Lemontag base.
  4. Find your Base ID in the Airtable URL: airtable.com/[BASE_ID]/... — it starts with app
  5. Enter both values below and click Test Connection.
